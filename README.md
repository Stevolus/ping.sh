# ping.sh
Ping multiple hosts or IPs from within a text file quickly.

I found myself in a situation where one of my tasks was to ping a massive list of IPs/hosts as part of a very broad, unorganized and unnecessarily complicated audit. Manipulating the output to a csv file and letting it run for hours proved time saving.
